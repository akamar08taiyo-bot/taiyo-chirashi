## 今回特に追加された必須機能

- 作成モード：**レンタル / 事例集 / 消耗品**
- 各モードで1・2・3・4・6・9レイアウト
- 消耗品モードは福祉用具の単位数・1〜3割負担を完全非表示
- 消耗品は大分類→細かな種類を多数選択可能、かつ両方自由入力・編集可能
- 商品名、品番、規格・容量、入数・包装、説明、価格を保存
- 価格は全体ON/OFF + 商品別ON/OFF
- 長い商品名は「自動縮小→意味の切れ目で最大2行→手動改行優先」。括弧や型番・容量途中などの不自然な分断を避ける
- 文言サンプル多数 + 完全手入力
- 19営業所選択で営業所名・住所・TEL・FAXを自動切替
- 担当名・携帯番号は一度入力したら社員ごとに記憶
- ロゴ表示ON/OFF
- A4プレビュー上の直接編集
- 縦長／横長写真の全体表示・枠いっぱい表示
- PDF/PNG/JPEG/直接印刷/PNG印刷

## デバッグ

現行引き継ぎ時点では `npm run check` が38/38成功しています。ただし、引き継ぎ環境ではChromiumのlocalhostアクセスが管理ポリシーで遮断されて最新追加分のフルE2Eを完走できませんでした。あなたの環境では必ず実ブラウザE2Eを行ってください。

最低限、ログイン→新規作成→3モード→写真/商品入力→長い商品名→自動保存→再読込→オフライン→復旧→複製→テンプレート→共有RLS→削除/復元→AI→PDF/PNG/JPEG→PNG印刷/直接印刷まで通してください。PCとスマホも確認してください。

Supabaseを接続したら、private/office/companyのRLS、非公開Storage、署名URL、別社員のprivate作品取得不可、他営業所office作品取得不可、会社共有取得可をHTTP/APIレベルでも確認してください。

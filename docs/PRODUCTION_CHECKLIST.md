# 本番公開前チェックリスト

このチェックは、SupabaseとOpenAIを実プロジェクトへ接続した後に実施します。

## 1. 初期設定

- [ ] `supabase/migrations/` 配下のマイグレーション3本が番号順にエラーなく完了する
- [ ] `flyer-media` が非公開バケットになっている
- [ ] `company-assets` が非公開バケットになっている
- [ ] `ai-assist` Edge Functionが公開されている
- [ ] `admin-users` Edge Functionが公開されている
- [ ] `OPENAI_API_KEY` がEdge Function側だけに設定されている
- [ ] `APP_ORIGIN` が本番WebアプリURLになっている
- [ ] `config.js` にService Role KeyやOpenAI APIキーが入っていない

## 2. 認証・社員管理

テスト用に「営業所A 一般社員A」「営業所A 一般社員B」「営業所B 一般社員C」「営業所A 管理者」「全社管理者」を用意します。

- [ ] 社員ID＋パスワードでログインできる
- [ ] 画面へ内部認証メールが表示されない
- [ ] 誤ったパスワードはログインできない
- [ ] 利用停止した社員はログイン後のプロフィール取得が拒否される
- [ ] 利用停止しても、その社員が作った過去作品は残る
- [ ] 営業所管理者は自営業所の一般社員だけ追加・停止できる
- [ ] 全社管理者は全営業所・全社員を管理できる

## 3. RLS共有権限（最重要）

一般社員Aが3作品を作成します。

- 作品P: 自分だけ
- 作品O: 同じ営業所
- 作品C: 会社全体

確認:

- [ ] 一般社員Bは作品Pを一覧取得・直接URL取得できない
- [ ] 一般社員Bは作品Oを取得できる
- [ ] 一般社員Cは作品Oを一覧取得・直接URL取得できない
- [ ] 一般社員Cは作品Cを取得できる
- [ ] 全社管理者でも他社員の「自分だけ」作品は通常取得できない
- [ ] 権限のない作品IDをREST APIへ直接指定してもデータ本文が返らない

## 4. 写真Storage

- [ ] スマートフォン写真をアップロードできる
- [ ] 元画像と軽量プレビューが別オブジェクトになる
- [ ] 無認証状態でStorage URLへアクセスしても画像本文が取得できない
- [ ] 署名付きURLで権限のある社員だけ閲覧できる
- [ ] DBの `editor_state` に長い署名付きURLが保存されず `mediaId` が保存されている
- [ ] 「自分だけ」の写真が写真ライブラリ上では他社員に見えない
- [ ] その非公開写真を会社共有作品で使った場合、作品を閲覧できる社員は作品内の写真だけ表示できる
- [ ] JPEG / PNG / WebP以外が分かりやすいエラーで拒否される
- [ ] 20MB超の一般写真が拒否される

## 5. 作品・保存

- [ ] 19営業所が選択肢に表示される
- [ ] 営業所を変更すると営業所名・住所・TEL・FAXがA4へ即時反映される
- [ ] PDF / PNG / JPEGでも選択営業所の住所・TEL・FAXが反映される
- [ ] 担当名・携帯番号を入力し、新規作品を作成しても記憶されている
- [ ] 別PCでログインした場合も本番プロフィールから担当名・携帯番号が復元される
- [ ] 文言サンプルを選ぶと入力欄へ入り、その後自由に手入力で修正できる

- [ ] 新規作成3ステップが動く
- [ ] 1 / 2 / 3 / 4 / 6 / 9枚がすべて動く
- [ ] 9枚同時アップロードで枠1〜9へ順に入る
- [ ] 写真ドラッグ並び替えが動く
- [ ] 拡大、位置、回転、削除、差し替えが動く
- [ ] 月額3,000円で1割300円 / 2割600円 / 3割900円になる
- [ ] 自動保存が1文字ごとではなくデバウンスされる
- [ ] 「保存中…」→「保存しました」へ変わる
- [ ] ページ再読み込み後も編集内容が残る
- [ ] オフライン中の編集がIndexedDBへ残る
- [ ] 復旧後に自動同期する
- [ ] 同じ作品を2ブラウザで編集するとversion競合を検知する
- [ ] 競合時に無条件上書きされない
- [ ] 「自分の内容を複製して残す」が動く

## 6. テンプレート・ライブラリ・ゴミ箱

- [ ] 個人テンプレートが他社員に見えない
- [ ] 営業所テンプレートが同営業所で使える
- [ ] 全社テンプレートが全営業所で使える
- [ ] 商品写真 / 事例写真で分類できる
- [ ] カテゴリー / メーカー / 商品名で検索できる
- [ ] 作品の複製ができる
- [ ] 削除した作品がゴミ箱へ移る
- [ ] ゴミ箱から復元できる
- [ ] 削除から30日未満は完全削除できない

## 7. 3モード・消耗品

- [ ] 新規作成STEP1でレンタル / 事例集 / 消耗品を選べる
- [ ] 編集中に3モードを切り替えても入力済みデータが勝手に消えない
- [ ] 各モードで1 / 2 / 3 / 4 / 6 / 9レイアウトが動く
- [ ] 消耗品モードでは単位数・1〜3割負担がUI/A4/PDF/PNG/JPEG/印刷に出ない
- [ ] 消耗品の大分類候補と細かな種類候補を選べる
- [ ] 大分類と種類をどちらも自由入力・変更できる
- [ ] 商品名 / 品番 / 規格・容量 / 入数・包装 / 説明 / 価格が保存・再読込される
- [ ] 価格の全体ON/OFFと商品別ON/OFFが一致する
- [ ] 長い商品名が不自然な途中で折り返さず、括弧途中を極力避ける
- [ ] 手動で指定した商品名改行を保持する
- [ ] 6商品・9商品でも商品名・価格・説明がクリップしない
- [ ] 文言サンプルを選んだ後、完全に手入力で修正できる

## 8. AI文章補助

- [ ] 「AIで文章を整える」が動く
- [ ] 「メモから説明文を作る」が動く
- [ ] AIの提案が本文へ自動上書きされない
- [ ] 入力にない病名、身体状況、商品名、メーカー、利用者属性などを勝手に追加しない
- [ ] OpenAI側エラーでも入力本文が消えない
- [ ] ブラウザDevToolsのNetwork/SourceにOpenAI APIキーが出ない

## 9. A4出力

- [ ] A4縦PNGが2480×3508px
- [ ] A4横PNGが3508×2480px
- [ ] JPEGが開ける
- [ ] PDFがPDFビューアで開ける
- [ ] 画面サイズを変えてもA4の配置が変わらない
- [ ] 写真未設定・画像読込失敗・文章はみ出しが出力前に具体的に表示される
- [ ] 直接印刷でA4縦横が正しく指定される

## 10. UI

- [ ] 1366×768程度のPCで3カラムが破綻しない
- [ ] 1600×1000程度のPCで中央A4が主役として見える
- [ ] iPhone相当幅でログイン、ホーム、作品確認、写真ライブラリが横にはみ出さない
- [ ] 技術的なDBエラー文が一般社員へそのまま表示されない
- [ ] ブラウザコンソールに未処理エラーが残らない

## 11. 公開判定

上記で失敗した項目は、原因と修正内容を残して再テストします。特に「RLS共有権限」「非公開Storage」「APIキー非露出」「利用停止社員」「競合上書き防止」に1件でも未確認・失敗がある状態では本番公開しません。

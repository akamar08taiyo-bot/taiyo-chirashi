# ケアマネジャー様向け チラシ作成ツール

太陽シルバーサービス株式会社／福祉用具チラシ作成ツール（静的サイト・依存パッケージなし）

## 編集とデプロイ

編集するのは `dc-src/index.dc.html` です。編集したら次のコマンドで配信用の
`index.html`（リポジトリ直下）へ反映します。

```
node scripts/build-flyer.mjs
```

ローカル確認は `dc-src/index.dc.html` を HTTP サーバ経由で開きます。

```
python -m http.server 4173
# → http://localhost:4173/dc-src/index.dc.html
```

`index.html` は単体で動作する完成ファイルです（依存なし）。

```
# Vercel
vercel deploy --prod

# Netlify
netlify deploy --prod --dir=.

# GitHub Pages
# index.html をリポジトリ直下に置いて Pages を有効化
```

publish directory はこのフォルダ、entry は `index.html` を指定してください。

## ファイル構成

| パス | 内容 |
|---|---|
| `index.html` | 配信用。ランタイム・フォント・スクリプトを全て内包した自己完結ファイル（約7MB） |
| `dc-src/index.dc.html` | **編集用ソース。ここだけを直します** |
| `dc-src/support.js` | ランタイム（React + テンプレートエンジン）。編集不要 |
| `scripts/build-flyer.mjs` | `dc-src` の内容を `index.html` へ反映するビルドスクリプト |

`dc-src/index.dc.html` の `onClick` / `<select>` / `<br>` などの書き方は
`support.js` が読み込み時に変換するため、ビルド時の変換は不要です。

## 機能

- チラシ5種：特価ベッド／新商品／導入事例／おすすめ用具／消耗品チラシ
- 用具の種類：貸与13種目・特定福祉用具販売6種目・住宅改修6種目
- 区分（貸与／販売／住宅改修／自費）で給付対象・負担額表示が自動切替
- 19営業所を選択すると住所・TEL・FAX・介護保険事業所番号・担当者名を自動入力
- 写真はクリック選択／ドラッグ＆ドロップ／貼り付けに対応
- 画像ファイルはプレビューのA4紙面の枠へ直接ドロップできる（入れたい枠に落とせる）
- 編集欄の写真枠はつまんで別の枠へ移せる（写真の入れ替え）
- スクリーンショットやコピーした画像は「貼り付け」ボタン、または Ctrl+V（⌘V）で入る。
  貼り付け先はプレビューの枠をクリックして選べる
- 取り込んだ写真は枠いっぱいに入るため、上下に空白の帯が残りません
- プレビューの写真をドラッグして、写す位置（切り取る場所）を決められます
- 導入事例は1・2・4・6・9枚、消耗品チラシは1・2・3・4・6・9商品を掲載可
- A4縦1枚で印刷／PDF出力（入力フォームは印刷対象外）

### 仕上がり・印刷の設定（プレビュー上部）

| 設定 | 内容 |
|---|---|
| 写真の自動調整 | 取り込んだ写真の余白を切り取り、枠に合わせて「枠いっぱい／全体を写す」を自動選択します |
| プレビューの大きさ | 標準（480px）／大きく（原寸794px） |

A4 1枚に収まらないときは紙面全体を自動で縮小します（下限62%）。
縮小率と「収まりません」の警告はカード上部に表示します。用紙のふち（余白）は常に0で、
いずれも設定項目は持ちません。

写真は1枚ごとに「自動調整」「枠いっぱい⇄全体を写す」「大きさ 40〜250%」「元に戻す」「位置を中央」で
調整できます。取り込んだ写真は長辺1600pxに縮小されるため、スマホ写真でも動作が重くなりません。

**スクリーンショットの貼り付け**：写真ごとの「貼り付け」ボタン（商品写真は「スクショを貼り付け」）を押すと、
クリップボードの画像をその枠へ入れます。クリップボードを直接読めないブラウザでは、その枠を貼り付け先に選んだうえで
「Ctrl+V（⌘V）を押してください」と案内します。Ctrl+V（⌘V）はどこを操作していても効き、
貼り付け先が選ばれていなければ空いている枠へ順番に入ります。貼り付け先はプレビューの枠をクリックしても選べます
（選ばれている枠は画面上だけ枠線で示され、印刷には出ません）。Webページからコピーした画像（クリップボードに
画像そのものではなくURLだけが入る場合）も、取得できるものは貼り付けられます。結果はプレビュー上部に短い案内で出ます。

**ドラッグ＆ドロップ**：画像ファイルは、編集欄の枠だけでなく、プレビューのA4紙面の枠へ直接ドロップできます。
落とした枠にそのまま入るので、どの枠に入るか迷いません（ドロップ先の枠は点線で示されます）。
編集欄の写真枠はつまんで別の枠へドロップすると、写真の表示方法・大きさ・位置ごと入れ替わります
（空の枠へ落とせば移動になります）。ブラウザの別タブから画像そのものをドラッグしてきた場合も、
取得できるものはそのまま入ります。

**写真の位置・切り取り**：プレビューの写真をマウス（タッチ）でドラッグすると、枠の中で写真が動きます。
写真の上にカーソルを置くと「ドラッグで位置を調整」と出ます（画面のみ・印刷には出ません）。
「大きさ」で拡大してからドラッグすれば、写真の好きな部分だけを切り取って載せられます。
位置は写真ごとに保持され、印刷・PDFにもそのまま反映されます。中央へ戻すときは「位置を中央」を押します。

決まった高さの枠に入る文字（消耗品の商品名・規格、複数品の商品名・説明、事例のコメント）は
枠に収まるまで自動で小さくなります。最小サイズでも入らない場合は行単位で表示を止め、
プレビュー上部に警告を出します。

## 中身の構造

`src/index.dc.html` は3つのパートで構成されています。

1. **`<x-dc>` 内のマークアップ** — 左の入力フォームと右のA4プレビュー。スタイルは全てインライン
2. **`<script data-dc-script>` 内の `class Component`** — 状態管理とデータ。`renderVals()` の戻り値がテンプレートの `{{ }}` に入ります
3. **データ定数** — スクリプト冒頭

### データを直す場所

| 定数 | 内容 |
|---|---|
| `OFFICES` | 19営業所の住所・TEL・FAX・事業所番号（`j`）・所長名（`c`）。異動時はここを直します |
| `CATS` | 用具マスタ。貸与13種目／特定販売6種目／住宅改修6種目。各項目の `tani`（単位数）`price`（価格）`fee1`（1割負担額）`kyufu`（給付対象）`feats`（特徴3点） |
| `SHOMO` | 消耗品の既定リスト（商品名・規格・税込価格）9件 |
| `TPL` | チラシの型5種と既定の見出し |
| `SCOL` / `SROW` | 消耗品チラシの列数・行の高さ（商品数ごと） |
| `GRID` | 導入事例の写真グリッド（枚数ごとの列数・行数） |
| `KI` / `H` / `A` / `KYUFU` | 区分ごとの表記と給付対象の選択肢 |

2割・3割負担額は `fee1` から自動計算されます（`burdens()`）。

## 未確定事項

- 各種目の単位数・給付対象は仮値です。実運用前に自社設定・地域区分で要確認
- 特に **移動用リフト（つり具を除く）** の給付対象は要確認
- `SHOMO` の消耗品9件は仮の商品名・価格です
